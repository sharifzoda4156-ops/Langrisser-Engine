# Участие в проекте

Приветствуются код, воспроизводимые случаи из игры и исправления данных.
Самый полезный вклад игрока — точная ситуация, в которой результат можно проверить.

1. Укажите регион и версию игры, карту, сборки, солдат, эффекты и их длительности.
2. Опишите начальную позицию, последовательность действий и наблюдаемый результат.
3. Приложите источник или свою запись теста. Отделяйте наблюдение от объяснения.
4. Используйте [шаблон механики](docs/MECHANIC_CASE_TEMPLATE.md).

Новые герои будут добавляться после появления проверенного набора базовых механик.
Обещания «любой герой одним YAML без кода» проект не даёт. Сначала проверяется
поведение, затем выбирается подходящее описание: данные, общий эффект или обработчик.

Для кода: ветка → проверки → PR. Укажите проблему, итоговое поведение, проверки и
ограничения. Изменения правил требуют поведенческих тестов и обновления статуса.
В fixture запрещены настоящие имена героев и неподтверждённые игровые формулы.

```bash
python scripts/build_native.py
python -m unittest discover -s tests -v
```

В репозиторий не отправляются API-ключи, приватные инструкции, бинарники,
SQLite-базы, результаты обучения и чужие игровые ресурсы.
